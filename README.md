# 热点机会台 · 通用热梗发现与方案生成平台

## 定位
面向通用热梗、网感趋势和跨平台热点，完成：
**抓取热点 → 过滤噪音 → 研判机会 → 整理方案 → 输出归档**

发现层分为“今日焦点”和“行业动态”：前者收录泛娱乐网络大热梗，后者按手游、休闲向、娱乐向、MMO、RPG 分类。推荐与方案层再读取当前策略做适配判断。目前可把《杖剑传说》设为当前项目，之后也能切换到其他项目，复用同一套热点池。

## 快速启动
```
双击 start.bat
本机访问   http://localhost:4567
团队访问   http://<本机内网IP>:4567   （启动窗口会显示）
```
数据集中存储在服务器端 SQLite（data/zj_koc_v3.dat），团队成员浏览器访问即可协作，无需各自安装。

## Docker 部署
适合服务器部署和后续升级。代码放 Git，数据库通过 volume 挂载保留。

首次部署：
```bash
cp .env.example .env
docker compose up -d --build
```

访问：
```text
http://服务器IP:4567
```

后续升级：
```bash
git pull
docker compose up -d --build
```

如果使用 GitHub Actions 打好的镜像：
```bash
docker compose -f docker-compose.ghcr.yml pull
docker compose -f docker-compose.ghcr.yml up -d
```

数据库默认挂载在：
```text
server/data/zj_koc_v3.dat
```

注意：不要把 `.env`、`server/data/*.dat`、`node_modules/`、`dist/` 提交到 Git。

## 一级页面
| 页面 | 职责 |
|------|------|
| 热点雷达（默认首页） | 今日焦点、手游行业动态、发现评分、当前项目推荐与人工补录 |
| 机会中心 | 待研判 → 值得跟进 → 方案整理中 → 已输出，全程保留来源和日志 |
| 策略配置 | 按阶段管理目标、关键词、重点内容、平台偏好和风险规则 |
| 系统设置 | AI、自动任务及基础参数配置 |

## 推荐与评分逻辑
- **发现评分**：热梗/表达复用性 + 趋势强度 + 新鲜度 + 来源可追溯性，用于通用热点池排序
- **项目适配评分（兜底，永远可用）**：当前项目适配(35) + 热梗可复用性(25) + 趋势强度(20) + 新鲜度与可追溯性(20) − 风险扣分(最高30)
- **AI评估（OpenAI兼容中转站/Gemini）**：只基于热点、当前策略与可验证信息生成判断和方案，不读取作者库或案例库；失败时自动降级为规则打分

## 后台自动任务
- 服务启动后会开启每日自动任务，默认每天 **07:00（Asia/Shanghai）** 执行一次。
- 自动任务会抓取 B 站综合热门与游戏分区内容、抖音近 7 天的通用热梗和当前项目关键词具体视频；“行业动态”还会独立聚合机核、游戏陀螺与伽马数据的公开资讯，并保留原文来源和发布日期。抓取完成后立即生成项目适配推荐，并写入每日快照。
- 在左下角「系统设置」→「后台自动任务」可以查看运行状态、调整时间、手动立即执行。
- 环境变量可配置：`AUTO_TASK_ENABLED=1`、`AUTO_TASK_TIME=07:00`、`AUTO_TASK_BOOTSTRAP=1`。

### 抖音视频搜索配置
抖音来源使用开放平台 `aweme.dy.video_search` 能力，只保存可直达的具体视频链接，不使用平台总榜或搜索页假链接。在「系统设置」填写应用 AppID、AppSecret 和设备 ID 后可测试连通性；也可通过服务端环境变量 `DOUYIN_CLIENT_KEY`、`DOUYIN_CLIENT_SECRET`、`DOUYIN_DEVICE_ID` 配置。未配置时，页面会明确提示并仅展示其他平台的真实内容。

## 首次使用
1. 在「策略配置」建立当前阶段，补充关注关键词、重点内容和风险规则
2. 在「系统设置」确认 AI 配置（中转站或 Gemini），点击「测试AI连通性」
3. 打开「热点雷达」刷新候选热点，将值得关注的内容生成机会
4. 在「机会中心」研判、整理并输出方案

## 技术栈
Vue 3 + Vite + Node.js + Express + sql.js（SQLite，免编译），端口 4567。
